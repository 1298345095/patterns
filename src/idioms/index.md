# 惯用法

[惯用法](https://en.wikipedia.org/wiki/Programming_idiom)是社区广泛认可并经常采用的编程风格、准则和模式。遵循惯用法编写代码，能让其他开发者更容易理解代码的行为。

毕竟，计算机只关心编译器生成的机器码；源代码主要是为开发者服务的。既然有了这一层抽象，何不让它更易读呢？

请记住 [KISS 原则](https://en.wikipedia.org/wiki/KISS_principle)： “Keep It
Simple,
Stupid”（保持简单，别把事情弄复杂）。这一原则认为：“大多数系统在保持简单时表现最好，而不是越复杂越好；因此，简单应当成为设计的关键目标，并且应当避免不必要的复杂性。”

> 代码是写给人理解的，而不是写给计算机理解的。
